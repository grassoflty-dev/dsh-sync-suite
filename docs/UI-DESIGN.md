# UI 设计规范与重构方案（UI-DESIGN）

> 目标（用户原话）：**「页面太丑太繁杂了，而且还要支持竖屏和横屏两种 UI。」**
> 方向（已定）：白底 + 单一强调色 `$r('app.color.brand')` + 细分割线；去掉多余卡片/阴影/边框；
> 每屏 1 个主操作，其余收进「更多」；字号 3 级；触控 ≥40vp；深色跟随系统；不新增配置项。
>
> **能力边界**：模型无视觉能力，本审计**不基于截图观感**，只基于
> ①`devecocli ui layout --format json` 的结构化布局（控件/文字/bounds/层级）
> ②源码静态统计（字号/padding/margin/space/圆角/硬编码色/触控尺寸）。
> 截图仅作归档给用户验收，**不作为自动判据**。

## 4. 断点与栅格

| 断点 | 宽度(vp) | 列数 | Index | Edit | Detail | Settings |
| --- | --- | --- | --- | --- | --- | --- |
| `compact` | <600 | 1 | 日期条 → 模式 → 列表 → 新建 | 表单自上而下 | 正文 → 附件 | 单列分组 |
| `medium` | 600–840 | 2 | 左日期列 / 右列表 | 左表单 / 右预览 | 左正文 / 右附件 | 两列分组 |
| `expanded` | >840 | 2 | 同上，侧栏 420 上限 | 同上 | 同上 | 同上 |

- **横屏特例**：`resolveBreakpoint(width, landscape)` 在横屏下**至少返回 `medium`**（横屏拿宽度换高度，单列会把纵向挤爆）。
  因此页面只需 `breakpoint === 'compact'` 一个判断，不必各写方向判断。
- 侧栏宽：`sidebarWidth(contentWidth)` = 内容宽 1/3，夹在 280–420vp。
- 页面禁写阈值：`600/840` 只允许出现在 `uiTokens.ts` 与 `PageLayout`。

## 5. 旋转支持与手写板坐标系（只报告，不改 A 的文件）

1. **方向开关**：`entry/src/main/module.json5` 的 EntryAbility 增加 `"orientation": "auto_rotation"`（唯一字段改动）。
   若真机被平板策略限制为仅竖屏，回落 `auto_rotation_restricted`，并**如实记录**（本轮未验证：设备锁屏 + 需重新构建）。
2. **三点验证**（待构建后执行）：①布局重排（`onAreaChange` → 断点 compact↔medium/expanded，Index 单列↔双栏）；
   ②数据不丢（页面状态都在 `@State`，旋转只 relayout 不重建；列表/表单从 `@State` 重绘，写盘仍走 `appendRecord`）；
   ③手写板坐标系（下条）。
3. **手写板归一化坐标的旋转缺陷（只报告）**：
   - 笔迹是**像素坐标**：`HandwritingPager.ets:680 points.push({x: px, y: py})`，绘制直接用 (x,y)（:499-501）；
   - 框是**归一化坐标**：渲染 `box.x * this.canvasW`（:1418-1420），遮白 `regionsToMaskRects(boxes, W, H)`（`model/regions.ts:133`）；
   - 画布尺寸在 `onAreaChange` 里被**直接替换**（:1516-1519）。
   → 旋转后：框按新宽高比拉伸，笔迹停在旧像素位置 → **框与笔迹错位**，遮白盖错位置（框内笔迹会被送去 OCR，违反「框内不做 OCR」）；
   且**超出新画布的笔迹在截图里永久丢失**（不可回滚的数据损坏）。
4. **选择方案 b（手写页锁定方向 + UI 说明）**，理由：墨迹是像素坐标，方案 a（按新画布重投影归一化框）只能让框继续贴住旧像素墨迹，
   无法阻止墨迹跑出画布被裁掉，属于「看起来修好了、实际丢数据」；方案 b 用一次 `setPreferredOrientation`（或该页固定方向）就根除两类问题，
   且不引入坐标迁移风险。UI 上在状态行加一行说明：「手写板固定为进入时的方向，不跟随旋转」。
   **若产品要求手写页也跟随旋转**：必须先把 `Stroke.points` 迁移为归一化坐标（`handwriting/**`，A 的文件），
   让墨迹与框同源缩放，再撤掉锁方向——本轮**只报告，未改动** `entry/src/harmony/ets/{handwriting,ocr}/**`。
