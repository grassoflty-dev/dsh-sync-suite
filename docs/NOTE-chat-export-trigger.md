# 设计注记：会话发布（chat export）的用户入口 —— 2026-11-28

> 性质：**设计注记，不是模块设计，不授权任何代码**。用户尚未决定是否要这个入口。

## 0 为什么写这一页
docs\CHAT-DELETE-DESIGN.md 的前提是"会话记录在云端仓库里"。实测：~\.dsh\dots\repos\83b24a6a05769119\git-repo\chats\ **不存在**，chats\index.jsonl **不存在**，chats\ 下 **0 个目录**；另一个仓库 258a512f0eb7b01d 也没有。电脑上有 **2,225** 个会话 .zstd 日志，**一条都没发布过**。

原因不是"功能被关掉"，是**半边接线**：发布能力只以 RPC 形式存在（src\rpc.ts:1355-1360 的 chatExportStatus / chatExportAll / chatExportOne，落到 exportChatsToRepo :984/:999），而面板 src\client.js **没有任何 chatExport 引用**、locale\zh.json **没有对应文案**、src\sync\cycle.ts 与 src\index.ts **没有任何 chat 触发**；平板侧只有一个能力位（model\instances.ts:77-78,320）。所以平板的会话列表一直是空的，且界面上没有任何一句话解释为什么。

## 1 入口放在哪
面板（电脑端 DSH 插件设置区）里一行，紧邻「远程控制」分组，标题直白：**「发布会话到仓库」**。不做自动、不做后台、不做定时——发布会把**对话正文**写进云端 Git 仓库，这是用户对自己内容的授权动作，必须由他点击并确认。

## 2 确认层说什么（两行，缺一不可）
1. 「将把本机 <N> 个会话（按时间倒序，最多 <limit> 个）发布到同步仓库的 chats/；发布后平板与电脑都能看到这些会话。」
2. 「对话正文会进入云端 Git 历史，**发布后无法从历史中抹除**（可以用"删除"从列表隐藏，但字节仍在）。」
按钮：**「发布」** / 「取消」。默认不勾选任何"记住此选择"，不提供"以后自动发布"。

## 3 单个还是全部
先做**全部（按上限）**一个动作：chatExportAll（pc.ts:1358），默认上限沿用现有 
ormalizeLimit（index.ts 侧），面板显示"将发布 N 个 / 共 M 个"。单条发布（chatExportOne :1360）作为**同一入口的次级动作**（列表行尾的「只发布这一条」），不在第一版出现——理由：一个会话单独发布会让人以为其余会话已同步，反而更容易造成误解。

## 4 发布之后用户看到什么
- 入口那一行变成结果行：已发布 12 个 · 12:03（时间来自 lastSyncAt 同风格 ISO，本模块自己的时间字段），失败则 发布失败：<typed 原因>，最多一句中文原因，不回显 URL/token。
- 旁边一个「再次发布」按钮（等价于重跑同一动作，**不自动重试**）。
- 平板端不需要新 UI：chats/index.jsonl 一旦有行，现有的 chatStore 读取路径自然显示。
- 空态文案（电脑与平板一致）：「仓库里还没有会话。在电脑端设置里点『发布会话到仓库』。」

## 5 明确**不**做什么
- 不后台自动发布、不"打开 DSH 就发布"、不定时发布；
- 不重试、不静默补发；失败就停在那里并显示原因；
- 不发布会话里被隐私过滤规则拦掉的字段（exportChats.ts 现有 edactSecrets / scanForLeaks 保持原样，**不放宽**）；
- 不因为"用户点过一次"就记住授权；
- 不动 chats/<id>/** 的读取语义，也不与 mod-chat-hide 的隐藏集合互相改写。

## 6 验收（将来实现时的最小集）
- 点击 → 确认 → 发布：仓库出现 chats/index.jsonl 一行 + chats/<id>/ 两文件；平板列表出现该会话；
- 取消 → 仓库**零变化**（逐文件 sha256 不变）；
- 发布失败（鉴权/网络）→ 面板显示 typed 原因，仓库零残留提交（或明确说明已提交未推送）；
- 无 token / 无 URL / 无 ?／会话正文出现在任何日志或面板文本里（grep 断言）。

## 7 未定（只有用户能定）
1. 是否要这个入口（没有它，会话列表永远是空的）；
2. 默认上限（全部？最近 N 条？）；
3. 是否允许"只发布这一条"；
4. 发布后会话被删除/隐藏时，仓库里的载荷是否也要清理（当前设计：**不清**，只隐藏）。
