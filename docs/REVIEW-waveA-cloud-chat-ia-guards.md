Required fix: assert on a semantic anchor (e.g. a named callback wired to the single bottom action, or the `ActionButton` invocation) in addition to the literal, or narrow the claim in the test title from "exactly one primary action" to "exactly one `Button('…')` literal".

Required fix: drop the dead loop and rename the test to "root declares no anchor mechanism", or move the chip↔row consistency check to a file that actually declares chips so the rule can be exercised.
